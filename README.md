# AI Study Assistant

AI Study Assistant is a Streamlit application that helps students process study materials.

## Current Features

- Upload a PDF document
- Display the PDF page count
- Preview text from the first page
- Extract and clean text from the complete PDF
- Display character and word counts
- Generate an AI-powered summary using OpenRouter
- Warn users when a PDF contains no readable text

## Technologies Used

- Python
- Streamlit
- PyPDF
- OpenRouter API
- OpenAI Python library

## Project Status

The PDF upload, text extraction, text cleaning, and summary generation features are complete.

Flashcard generation will be added in the next development stage.
